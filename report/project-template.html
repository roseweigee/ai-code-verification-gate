SpecBlast · AI Code Verification Gate

SpecBlast Project Gate

SpecBlast generates a Spring Boot service and its Kubernetes deployment from an API spec. The gate checks that output before Cloud Build is allowed to deploy it, and a named human approves what is left.

Where the gate sits

API specApproved by a person
→
SpecBlastAI generates code, K8s and pipeline
→
mvn verify + SonarMockito tests, coverage, quality gate
→
Verification gateP1–P7 decide. Exit 1 stops the build
→
Human approvalNamed reviewer accepts warnings
→
Cloud BuildDeploys the image for this commit

The same gate is also exposed as an MCP tool, so a coding agent can check its own output while it works. The tool reports the verdict; it cannot approve a deployment.
